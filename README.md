# JavaScript Functions and Loops

A collection of JavaScript practice problems focused on understanding and implementing functions and loops to improve logical thinking and problem-solving skills.

## Problems Covered
- Even or Odd Checker
- Result Evaluator
- Maximum Finder
- Sum of N Numbers
- Multiplication Table
- Digit Counter
- Number Reverser
- Factorial Calculator
- Prime Number Checker
- Pattern Printing

## Concepts Used
- Function Declaration
- Function Expressions
- Arrow Functions
- For Loop
- While Loop
- Nested Loops

## Technologies Used
- JavaScript (ES6+)
- Node.js

## Purpose
To strengthen understanding of JavaScript functions and loops through practical coding exercises and logical problem-solving.
